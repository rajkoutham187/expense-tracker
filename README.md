# Expense Tracker 💰

A simple web application for tracking daily expenses.

## Features

- Add expenses
- Select expense categories
- Delete expenses
- Calculate total expenses
- Save expenses using browser Local Storage
- Simple and responsive interface

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Start adding your expenses.

## Project Purpose

This project was created to practice front-end web development and JavaScript.
